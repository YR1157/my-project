# 🌪️ 龙卷风网站

一个炫酷的龙卷风主题网站，展示自然界的壮观力量。

## 🌐 在线预览

**访问地址**: https://YR1157.github.io/my-project/

## ✨ 功能特性

- 🎨 **炫酷动画** - 动态龙卷风旋转效果
- 📊 **等级展示** - EF0-EF5 龙卷风等级可视化
- 💫 **粒子效果** - 背景漂浮粒子
- 📱 **响应式设计** - 完美适配手机/平板/电脑
- ⚠️ **安全知识** - 龙卷风避险指南

## 🛠️ 技术栈

- HTML5
- CSS3 (动画、渐变、Flexbox/Grid)
- JavaScript (ES6+)
